# reborn 경량 웹

천천히, 한 단계씩 말하기를 연습하는 웹. 1단계(목소리) → 2단계(아바타) → 3단계(실전 면접) 순서로 진행한다.

- `frontend/`: 화면 (React + TypeScript + Vite)
- `backend/`: 서버 (Flask)
- `render.yaml`: Render 배포 설정 (화면은 Static Site, 서버는 Web Service)
- 용어는 `GLOSSARY.md`를 본다.

## 내 컴퓨터에서 실행

```
cd backend && pip install -r requirements.txt && python app.py
cd frontend && npm install && npm run dev
```
